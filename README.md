# Mojito Website

Bar/restaurant website with animations built with React and GSAP.

## Technologies

- **React 19.2** - UI framework
- **Vite** - build tool
- **GSAP 3.14** - animation library
- **Tailwind CSS 4.1** - styling
- **react-responsive** - responsive breakpoints

## Structure

The project contains the following sections:

- Navbar - navigation menu
- Hero - hero section with video background
- Cocktails - cocktail list
- About - bar information
- Art - gallery
- Menu - food menu
- Contact - contact form

## Installation

```bash
npm install
```

## Usage

Development server:

```bash
npm run dev
```

Production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## GSAP Animations

The project uses the following GSAP plugins:

- ScrollTrigger - scroll-based animations
- SplitText - text animations by characters and words

## Configuration

- `vite.config.js` - Vite configuration
- `eslint.config.js` - ESLint rules
- `constants/index.js` - menu and cocktails data
